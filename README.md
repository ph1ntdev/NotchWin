# NotchWin

Челка в стиле MacBook и верхняя панель как в macOS для Windows 10 и 11. Челка работает как Dynamic Island на iPhone: показывает музыку, уведомления, таймер, зарядку, а при наведении раскрывается в полноценную панель с вкладками.

> 🤖 Проект сделан с помощью ИИ: код и документацию написал Claude (Anthropic), а автор придумывал функции, тестировал каждую версию и решал, что оставить.

## Скачать

Готовая программа лежит во вкладке **Releases** справа на странице репозитория. Скачайте архив, распакуйте в любую папку и запустите `NotchWin.exe`:
- `win-x64-full.zip` работает сразу;
- `win-x64.zip` меньше, но нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).

## Запуск из исходников

Нужны Windows 10 (версия 2004 и новее) или Windows 11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
git clone https://github.com/<ваш-ник>/NotchWin.git
cd NotchWin/src/NotchWin
dotnet run
```

Также можно открыть `NotchWin.sln` в Visual Studio 2022 или Rider и нажать F5.

**Как выйти:** нажмите правой кнопкой по верхней панели и выберите «Выход». Если просто закрыть консоль, значки трея всё равно вернутся на панель задач Windows через пару секунд.

**Настройки:** правый клик по панели → «Настройки» или шестерёнка в раскрытой челке. Все изменения применяются сразу. Настройки хранятся в `%LOCALAPPDATA%\NotchWin\settings.json`.

## Возможности

### Верхняя панель

Панель резервирует место сверху экрана, поэтому развёрнутые окна начинаются под ней. Панель задач Windows остаётся внизу.

- **Название активной программы** слева.
- **Значки трея Windows.** Они переезжают с панели задач на верхнюю панель. Значки можно перетаскивать: менять порядок и прятать под стрелку.
- **Поиск** по Alt+Пробел: программы, файлы, калькулятор, исправление неправильной раскладки и поиск в интернете.
- **Погода** с прогнозом по часам и дням. Город определяется автоматически, его можно задать вручную.
- **Корзина.** Если перетащить на неё файл, она становится большой.
- **Раскладка клавиатуры.**
- **Громкость** с микшером по приложениям и выбором устройства вывода.
- **Батарея.**
- **Часы** со своим календарём.

Все выпадающие окна открываются плавно, с размытием фона, и закрываются кликом мимо них.

### Челка

В свёрнутом виде:
- обложка трека и эквалайзер в цвет обложки;
- зелёная и оранжевая точки, когда заняты камера и микрофон;
- «крылья» по бокам: таймер, загрузки, время звонка в Discord;
- живые уведомления: Telegram, ВКонтакте, сообщения программ из трея, зарядка и низкий заряд, громкость и яркость, флешки, окончание таймера.

При наведении раскрывается с вкладками:
- **Музыка:** любой плеер, который видит Windows (Spotify, браузер, ВК и т.д.), с перемоткой.
- **Полка:** временное место для файлов. Перетащите файл на челку, потом вытащите в любое окно. Скриншоты Win+Shift+S попадают сюда сами. Файлы можно отправить на телефон через [LocalSend](https://localsend.org) (это необязательно, функцию можно выключить).
- **Таймер и помодоро.**
- **Быстрая заметка:** в обычную папку или в хранилище Obsidian, если он установлен.
- **Wi-Fi и Bluetooth:** списки сетей и устройств прямо под значком.

### Ещё

- **Перевод выделенного текста** по Ctrl+Alt+T.
- **Discord:** кнопки «микрофон» и «звук» во время звонка, входящий звонок в челке.
- **Флешки:** появляются на полке, их можно безопасно извлечь.
- В полноэкранных играх и видео панель и челка прячутся.
- Автозапуск, выбор монитора и все горячие клавиши настраиваются.

## Ограничения Windows

- **Значки трея от программ, запущенных от имени администратора** (например, некоторые VPN), переезжают на панель, только если запустить такую программу после NotchWin.
- **Системные значки** сети, звука и батареи на панели задач Windows 11 нельзя убрать без сторонних модов вроде Windhawk.
- **Уведомления Telegram и ВКонтакте** берутся из центра уведомлений Windows, поэтому в самих программах уведомления Windows должны быть включены.
- **Для Discord** нужно назначить в Discord те же сочетания клавиш, что указаны в настройках NotchWin (по умолчанию Ctrl+Shift+Alt+M и Ctrl+Shift+Alt+D).
- **Список Wi-Fi сетей** в Windows 11 работает, только если приложениям разрешён доступ к местоположению.
- **Поиск файлов** использует индекс Windows Search. Если эта служба выключена, будут находиться только программы.
- **Яркость** показывается только для экрана ноутбука.
- **Alt+Пробел** может быть занят (например, PowerToys Run). Тогда поиск переходит на Ctrl+Alt+Пробел, а сочетание можно поменять в настройках.

## Если что-то не работает

Рядом с программой (`src/NotchWin/bin/Debug/net8.0-windows10.0.19041.0`) появляются журналы:

| Файл | Что в нём |
|---|---|
| `tray.log`, `tray-debug.log` | значки трея |
| `weather.log` | погода |
| `notifications.log` | уведомления Telegram и ВКонтакте |
| `media.log` | музыка и перемотка |

## Для разработчиков

Проект на WPF и .NET 8. WPF выбран потому, что челке нужно прозрачное окно нестандартной формы, сквозь которое проходят клики. В WPF это есть из коробки, а в WinUI 3 нормальной поддержки прозрачных окон нет.

```
NotchWin/
├── NotchWin.sln              решение для Visual Studio / Rider
├── README.md
├── .github/workflows/        сборка на GitHub Actions
└── src/NotchWin/             сам проект
    ├── App.xaml(.cs)         запуск и выход
    ├── TopBarWindow.*        верхняя панель
    ├── MainWindow.*          челка
    ├── SearchWindow.*        поиск
    ├── SettingsWindow.*      настройки
    ├── AppSettings.cs        все настройки и их значения по умолчанию
    ├── TrayHost.cs           значки трея Windows
    ├── PopupCloser.cs, Glass.cs   выпадающие окна и размытие
    └── Services/             погода, музыка, уведомления, LocalSend, Wi-Fi и т.д.
```

Каждый файл в `Services` отвечает за одну вещь, а названия говорят сами за себя (`WeatherService`, `TranslateService`, `RadioService` и т.д.).

Используемые библиотеки:
- [NAudio](https://github.com/naudio/NAudio): эквалайзер и громкость;
- [ManagedShell](https://github.com/cairoshell/ManagedShell): значки трея;
- Microsoft.Data.Sqlite: чтение уведомлений Windows;
- System.Data.OleDb: поиск файлов;
- System.Management: яркость и события устройств.

Сборка готовой программы:

```
dotnet publish src/NotchWin -c Release -r win-x64 --self-contained false -o out
```

Для запуска собранной так программы на другом компьютере нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). Если добавить `--self-contained true`, сборка будет работать без него, но станет заметно больше.
