# NotchWin

Челка в стиле MacBook для Windows, которая работает как Dynamic Island: сверху по центру экрана,
поверх всех окон, раскрывается при наведении и показывает полезные виджеты.

## Запуск

Нужны Windows 10 (2004+) или 11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
cd src/NotchWin
dotnet run
```

Или открыть `src/NotchWin/NotchWin.csproj` в Visual Studio 2022 / Rider и нажать F5.
Выход: правый клик по челке или по верхней панели → «Выход».

## Что уже есть

**Верхняя панель** как в macOS: полупрозрачная, резервирует место сверху, поэтому развёрнутые окна
начинаются под ней. Панель задач Windows с приложениями остаётся снизу.
- слева название активного приложения (на рабочем столе пусто);
- поиск (лупа или Alt+Пробел): приложения, файлы, калькулятор, поиск в Яндексе;
- погода: значок и температура, клик открывает прогноз на часы и дни;
- корзина: клик открывает её, правый клик — очистить; если навести файл, прямо над значком появляется
  большая красная корзина, бросьте файл туда;
- раскладка: клик переключает язык;
- громкость: микшер в стиле EarTrumpet, колесо мыши меняет громкость, правый клик выключает звук;
- батарея (если есть);
- часы: клик открывает свой календарь.

Все выпадающие окна со стеклом (размытием фона) и плавно открываются и закрываются.

**Челка** (свёрнутая совпадает с панелью по высоте):
- слева обложка трека, справа эквалайзер под музыку в цвет обложки;
- по центру зелёная точка, когда занята камера, и оранжевая, когда занят микрофон;
- таймер и загрузка живут в «крыльях»: челка раздвигается в обе стороны, слева обратный отсчёт,
  справа кружок, который заполняется по мере загрузки (наведите, чтобы увидеть детали);
- «живые» уведомления: сообщения Telegram и ВКонтакте, подключение зарядки, низкий заряд, громкость и яркость (вместо окна Windows), начало загрузки,
  копирование файлов в Проводнике, окончание таймера.

**Раскрытая челка** (при наведении), вкладки сверху:
- музыка: обложка вырастает из свёрнутой челки, трек, управление, перемотка;
- полка: перетащите файлы на челку, потом вытащите их из полки в любое окно;
  правый клик по файлу — закрепить (закреплённые не удаляются кнопкой «Очистить»);
  скриншоты Win+Shift+S сами попадают на полку; кнопка LocalSend отправляет файлы полки
  на телефон или ПК с LocalSend в той же сети (получатель подтверждает приём);
- заметка: вкладка с карандашом, текст уходит в ежедневную заметку Obsidian (Ctrl+Enter);
- таймер: линейка минут, Старт, во время работы +1 минута и Стоп (пауза), потом Сброс;
  пока идёт время, линейка едет к нулю; помодоро (25/5, после 4 циклов 15);
- справа сверху Wi-Fi и Bluetooth: наведите, и из значка «вырастет» окно со списком сетей
  или устройств; клик по значку включает и выключает радио; шестерёнка открывает настройки.

Правый клик везде открывает свои меню в стиле челки.

**Настройки** (правый клик → «Настройки» или шестерёнка): город для погоды или автоматическое место. Хранятся в `%LOCALAPPDATA%\NotchWin\settings.json`.

В полноэкранном режиме панель и челка прячутся. Пока программа запущена, часы на панели задач скрыты.

## Ограничения Windows

- Стандартное окно громкости Windows прячется только на Windows 10 и ранних сборках 11.
- Значки сети, звука и батареи на панели задач Windows 11 убрать нельзя без сторонних модов (Windhawk).
- Яркость показывается только на ноутбуках: внешние мониторы не сообщают Windows об изменении яркости.
- Уведомления Telegram и ВКонтакте берутся из центра уведомлений Windows: в Telegram должны быть
  включены уведомления Windows, ВКонтакте в браузере должен иметь право показывать уведомления.
- LocalSend отправляет только файлы, не папки.
- Музыка из ВК в браузере видна в плеере челки, но кнопки «добавить к себе» нет: у ВК закрыт API музыки.
- Для списка Wi-Fi сетей Windows 11 требует разрешить приложениям доступ к местоположению.
- Погода берётся из бесплатного Open-Meteo. Если она не загрузилась, причина пишется в окне погоды
  и в файл `weather.log` рядом с программой.
- Браузер не сообщает полный размер загружаемого файла, поэтому для загрузок кружок заполняется примерно.
- Поиск файлов использует индекс Windows Search: если служба поиска выключена, будут только приложения.
- Alt+Пробел может быть занят (например, PowerToys Run), тогда поиск висит на Ctrl+Alt+Пробел.
- На Windows 10 размытие у окон есть, но углы прямые.

## Почему WPF

| | WPF (.NET 8) | WinUI 3 | Tauri (Rust + WebView2) |
|---|---|---|---|
| Прозрачное окно произвольной формы | Да, из коробки (`AllowsTransparency`) | Нет нормальной поддержки, только обходные пути | Да |
| Клики сквозь прозрачные места | Да, автоматически | Сложно | Нужно вручную переключать |
| Поверх всех, без фокуса, вне Alt+Tab | Да, пара строк Win32 | Да | Да |
| Системные API (медиа, буфер обмена, уведомления) | Напрямую из C# | Напрямую из C# | Через крейт `windows`, больше кода |
| Плавность анимаций | Хорошая, GPU | Отличная | Хорошая (CSS) |
| Память в простое | ~40–60 МБ | ~60–90 МБ | ~80–150 МБ (WebView2) |
| Зрелость, примеры | Очень высокая | Средняя | Средняя |

Главная причина: челке нужно прозрачное окно нестандартной формы, сквозь которое проходят клики.
В WPF это работает из коробки, а в WinUI 3 прозрачных окон до сих пор толком нет. Tauri тоже
справляется, но доступ к медиа API и буферу обмена Windows из Rust заметно многословнее, а WebView2
держит лишнюю память ради маленькой полоски наверху.

## Структура

- `TopBarWindow.xaml(.cs)` — верхняя панель (AppBar), микшер, календарь, погода, корзина.
- `MainWindow.xaml(.cs)` — челка: форма, анимация, вкладки, уведомления, полка, таймер, Wi-Fi и Bluetooth.
- `SearchWindow.xaml(.cs)` — поиск как Spotlight.
- `SettingsWindow.xaml(.cs)`, `AppSettings.cs` — настройки.
- `Glass.cs`, `PopupCloser.cs` — стекло и плавные выпадающие окна.
- `Spring.cs` — пружинная физика анимации; `TimeRuler.cs` — линейка таймера.
- `MediaService.cs` — текущий плеер через `GlobalSystemMediaTransportControls`; `ColorExtractor.cs` — цвет обложки.
- `AudioVolume.cs`, `CoreAudio.cs` — громкость, устройства и приложения.
- `Services/AudioVisualizer.cs` — спектр системного звука для эквалайзера (NAudio).
- `Services/VolumeWatcher.cs` — изменения громкости и яркости, скрытие окна громкости Windows.
- `Services/LocalSendService.cs` — поиск устройств и отправка по протоколу LocalSend.
- `Services/NotificationWatcher.cs` — новые уведомления Telegram и ВКонтакте.
- `Services/ObsidianService.cs` — хранилище и ежедневная заметка Obsidian.
- `Services/PrivacyMonitor.cs` — камера и микрофон.
- `Services/TransferMonitor.cs` — загрузки и копирование.
- `Services/TimerService.cs`, `ChimePlayer.cs` — таймер и звук окончания.
- `Services/RadioService.cs` — Wi-Fi и Bluetooth.
- `Services/WeatherService.cs` — погода (Open-Meteo).
- `Services/RecycleBin.cs` — корзина.
- `Services/SearchProviders.cs`, `Services/ShellImage.cs` — источники поиска и значки.
